## About the Project

AI Compass is a curated directory designed to help users identify the right AI tools based on their intent. Whether the goal is design, coding, writing, productivity, or exploration, AI Compass delivers precise results through a clean, modern, and highly intuitive interface.

The project emphasizes a refined development philosophy often described as "Vibe Coding"—building functional products with premium design principles, smooth interactions, and a focus on user experience. AI Compass blends performance and aesthetics to create an efficient tool-discovery platform.

## Key Features

* Smart Intent Search that maps user queries to relevant AI tools.
* Dynamic Filtering to browse tools by categories such as Design, Coding, Writing, and Productivity.
* Premium User Interface incorporating dark mode, glassmorphism, and an animated bento-grid layout.
* Fast and lightweight deployment using Vercel v0.
* Fully responsive design optimized for desktop and mobile devices.

## Tech Stack

**Frontend:**

* React
* Tailwind CSS

**Deployment:**

* Vercel v0

## Getting Started

Follow the steps below to run AI Compass locally.

### Clone the repository

```
git clone https://github.com/your-username/ai-compass.git
cd ai-compass
```

### Install dependencies

```
npm install
```

### Start the development server

```
npm run dev
```

The project will be available at:

```
https://v0-build-ai-compass.vercel.app/
```
